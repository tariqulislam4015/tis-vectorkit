# VectorKit — Android অ্যাপ (APK) বানানোর নিয়ম

এই ফোল্ডারে VectorKit-এর পুরো Android প্রজেক্ট আছে। অ্যাপটি সম্পূর্ণ অফলাইনে চলে,
কোনো লগইন বা ইন্টারনেট লাগে না (শুধু বাংলা ফন্ট ইন্টারনেট থাকলে আরও সুন্দর দেখায়)।

## অ্যাপে যা আছে
- 📷 "ক্যামেরা দিয়ে ছবি তুলুন" চাপলে সরাসরি ফোনের ক্যামেরা খুলবে
- 🖼️ গ্যালারি থেকে ছবি নেওয়া যাবে
- ছবি দিলেই নিজে থেকে আকৃতি চিনে পরিষ্কার ভেক্টর আঁকবে (কোনো প্রম্পট লাগবে না)
- .AI / .SVG / .PDF / .PNG ফাইল সরাসরি ফোনের **Download/VectorKit** ফোল্ডারে সেভ হবে

## পদ্ধতি ১: Android Studio দিয়ে (ফ্রি, লগইন লাগে না)
1. https://developer.android.com/studio থেকে Android Studio ইনস্টল করুন।
2. Android Studio → **Open** → রিপোজিটরির `android` ফোল্ডারটি বাছুন।
3. প্রথমবার Gradle sync হতে কয়েক মিনিট লাগবে (ইন্টারনেট লাগবে)।
4. মেনু থেকে **Build → Build App Bundle(s) / APK(s) → Build APK(s)**।
5. তৈরি APK পাবেন: `app/build/outputs/apk/debug/app-debug.apk`
6. ফাইলটি ফোনে পাঠিয়ে ইনস্টল করুন ("Unknown sources" অনুমতি দিতে হতে পারে)।

## পদ্ধতি ২: কমান্ড লাইন দিয়ে
Android SDK ইনস্টল থাকলে:
```
./gradlew assembleDebug        (Windows: gradlew.bat assembleDebug)
```

## পদ্ধতি ৩: GitHub নিজেই বানিয়ে দেয় (সবচেয়ে সহজ)
`main` ব্রাঞ্চে কোড পুশ করলেই GitHub Actions নিজে থেকে APK বানিয়ে রিপোজিটরির **Releases** পাতায়
রেখে দেয়। সেখান থেকে যে কেউ লগইন ছাড়াই `TIS-VectorKit.apk` ডাউনলোড করতে পারবে।

## অ্যাপ আপডেট করা
রিপোজিটরির মূল ফোল্ডারের `index.html` ফাইলটিই পুরো সফটওয়্যার। APK বানানোর সময় এটি নিজে থেকেই
অ্যাপের ভেতরে কপি হয়ে যায়।
